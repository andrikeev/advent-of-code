[Advent of Code][aoc] – An annual event of Christmas-oriented programming challenges started December 2015. Every year since then, beginning on the first day of December, a programming puzzle is published every day for twenty-five days. You can solve the puzzle and provide an answer using the language of your choice.

All solutions here are written in Kotlin.

## Repository layout

```
AoC/src/
├── Utils.kt              shared helpers: grids, points, directions, BFS, parsing
├── Year2015/DayNN.kt     one file per day
├── Year2021/
│   ├── DayNN/            days 1–8 predate the current layout: one file per part
│   └── DayNN.kt
├── Year2022/DayNN.kt
├── Year2023/DayNN.kt
├── Year2024/DayNN.kt
└── Year2025/DayNN.kt

AoC/res/                  puzzle inputs — not committed, see below
.aoc_tiles/tiles/         generated tile images shown above
.github/workflows/        tile regeneration
```

## Running a solution

The project has no build file yet — open the repository in IntelliJ IDEA and run
the `main` function of the day you want. The working directory of the run
configuration must be `AoC/`, because inputs are resolved relative to it.

## Puzzle inputs

Inputs are deliberately not committed: Advent of Code [asks that they not be
republished][aoc-inputs], and they differ per account. `AoC/res/` is gitignored,
so download your own and place them as:

```
AoC/res/Year2024/Day01.txt          most years
AoC/res/Year2021/Day01/input.txt    2021, days 1–8
```

A day fails with a `FileNotFoundException` when its input is missing.

## Tiles

The graphic at the top is generated by [aoc-tiles][aoc-tiles] and refreshed
automatically by [`.github/workflows/aoc-tiles.yml`](.github/workflows/aoc-tiles.yml)
whenever solutions under `AoC/src/` are pushed. Everything between the
`AOC TILES BEGIN` and `AOC TILES END` markers above is overwritten on each run,
so edit it only through the tool.

Solve time and rank come from the personal AoC leaderboard, which needs
authentication. Store the `session` cookie from adventofcode.com as a repository
secret named `AOC_SESSION_COOKIE` (Settings → Secrets and variables → Actions).
It expires roughly every 30 days and has to be refreshed. Without the secret the
workflow still succeeds, but the tiles show plain checkmarks instead of times.

To regenerate locally instead, put the same cookie in `.aoc_tiles/session.cookie`
(gitignored) and run:

```
pip install aoc-tiles==0.7.2
aoc-tiles --aoc-dir . --count-as-solved-when on_leaderboard --what-to-show-on-right-side time_and_rank
```
